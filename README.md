# Programação Orientada a Objetos (POO) — Sistemas de Informação

Este repositório reúne **códigos e exemplos em C#** utilizados na disciplina de **Programação Orientada a Objetos (POO)** do curso de **Sistemas de Informação**.

## Objetivo
Disponibilizar, de forma organizada, os **arquivos `.cs`** apresentados em sala de aula, além de **códigos adicionais** quando necessário (ex.: complementos de exercícios, variações de exemplos, revisões e materiais de apoio).

## O que você vai encontrar aqui
- Exemplos vistos em aula (classes, objetos, construtores, encapsulamento, herança, polimorfismo, interfaces etc.)
- Exercícios e resoluções (quando disponibilizados)
- Códigos extras para reforçar conteúdos ou tirar dúvidas comuns
